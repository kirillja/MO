## Задача

Реализовать метод ломаных Пиявского для поиска глобального минимума одномерной липшицевой функции на отрезке.

Тестовый пример:

```text
f(x) = x**2 - 10*cos(2*pi*x) + 10
a = -5.12
b = 5.12
eps = 0.01
```

Для функции Растригина

```text
f'(x) = 2*x + 20*pi*sin(2*pi*x)
```

поэтому на выбранном отрезке можно взять

```text
L = 2*5.12 + 20*pi = 73.071853071796
```

## Запуск

```bash
pip install -r requirements.txt
python main.py --demo
```

Для своей функции:

```bash
python main.py -f "x**2 - 10*cos(2*pi*x) + 10" --a -5.12 --b 5.12 --eps 0.01 --L 73.071853071796
```

`L` передаётся отдельно, потому что для произвольной функции её корректную константу Липшица нужно знать или обосновать заранее.

## Результат

```text
x_min ≈ 0.000000000000
f(x_min) ≈ 0.000000000000
Итераций: 151
Вычислений функции: 153
Время: 0.008189 с
```

Алгоритм строит нижнюю липшицеву ломаную и выбирает следующую точку по минимальной вершине этой ломаной. Равномерная сетка используется только для построения графиков.
